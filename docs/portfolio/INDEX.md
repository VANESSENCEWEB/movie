# Pacote de documentação do repositório oficial

Use estes arquivos quando for criar / publicar o GitHub oficial do projeto.

| Arquivo | O que é |
|---|---|
| [README.md](./README.md) | README completo (estilo portfólio / nasa-explorer) — copie para a raiz do repo oficial |
| [GUIA_PUBLICACAO.md](./GUIA_PUBLICACAO.md) | Plano dia a dia + textos prontos de commit |
| [ESTRUTURA_E_BREADCRUMBS.md](./ESTRUTURA_E_BREADCRUMBS.md) | Pastas + hierarquia Início → Apartamentos → Bairro → Imóvel |

## Como usar em 3 passos

1. Leia a **estrutura e breadcrumbs**
2. Siga o **guia de publicação** (um dia por vez)
3. No último dia, publique o **README completo** na raiz do repositório oficial
